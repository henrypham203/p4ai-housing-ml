# Input datasets

Place the original CSV files in this folder using these exact names:

- `Housing.csv` — https://www.kaggle.com/datasets/yasserh/housing-prices-dataset
- `kc_house_data.csv` — https://www.kaggle.com/datasets/harlfoxem/housesalesprediction

Raw dataset files are not included in this repository package. Download them from the source and follow the dataset license/terms. The scripts preserve row order and use the saved split indices under `results/splits/`; do not sort or manually edit either CSV after creating the split files.
